# Мои рецепты

Кулинарная книга-PWA: распознавание рукописных и печатных рецептов со сканов,
автозаполнение разделов (название, ингредиенты, приготовление), поиск по словам
из названия и ингредиентам, режим готовки, архивные копии, темы и шрифты.

## Размещение
Загрузите все файлы в корень репозитория (GitHub Pages) или на поддомен сайта.
Файлы: index.html, sw.js, manifest.webmanifest, иконки (*.png), LICENSE.txt.

## Распознавание рукописного текста
Настройки → Распознавание → ключ Gemini (бесплатно: aistudio.google.com/apikey)
или Claude (console.anthropic.com). Офлайн-режим (tesseract.js) — для печатного текста.
